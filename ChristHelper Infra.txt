CHRISTHELPER – TECHNICAL OVERVIEW (v3 – PRODUCTION READY STATE)

============================================================
1. PROJECT OVERVIEW
============================================================

ChristHelper is a Christian support platform designed to connect people and ministries that need help with supporters who want to contribute.

The platform supports different kinds of help, including:
- Financial support
- Prayer support
- Guidance / mentorship
- Volunteer help
- Replies / encouragement

Main business idea:
- A user can create a project explaining a Christian need
- Other users can browse projects and support them
- Financial projects go through admin review
- Project owners can connect Stripe to receive funds
- Supporters can donate securely via Stripe Checkout
- Stripe Connect is used so funds can be routed to the project owner
- ChristHelper may also receive a platform support amount

Core functional areas:
- Public project browsing
- Project details page
- Prayer and reply interactions
- User registration and login
- User profile and preferences
- Stripe Connect onboarding and Stripe summary
- Project submission
- Admin review / approval / denial / cancellation
- Donation checkout and webhook processing

2. CURRENT ARCHITECTURE
============================================================

Architecture type:
- Simple separated frontend and backend
- Frontend and backend are in the same GitHub repo, but in separate folders

  christhelper/
    frontend/
    backend/

Frontend:
- Static HTML / CSS / Vanilla JavaScript
- Hosted in Azure Storage Static Website
- Delivered globally via Azure Front Door

Canonical frontend domain:
https://www.christhelper.com

Root domain behavior:
https://christhelper.com → 301 redirect → https://www.christhelper.com

Backend:
- Node.js + Express
- Hosted in Azure App Service

Backend domain:
https://api.christhelper.com

Data:
- SQLite in production
- DB path:
  /home/site/data/christhelper.db

Payments:
- Stripe Checkout
- Stripe Connect Express accounts

Webhook endpoint:
https://api.christhelper.com/webhook

Deployment model:
- Frontend → GitHub Actions → Azure Storage ($web)
- Front Door → global delivery + HTTPS
- Backend → GitHub → Azure App Service

DNS / domains:
- www.christhelper.com → Front Door (CNAME)
- christhelper.com → Front Door (A record → IP)
- Redirect handled at Front Door (Rule Set)
- api.christhelper.com → App Service
